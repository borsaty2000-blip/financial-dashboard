# @borsaty/widgets

حزمة لوحة تحكم معيارية قابلة للتخصيص.

## الوظائف

- 12 نوع Widget مسجل بعقد صريح.
- `DashboardGrid` يدعم native drag-and-drop وتبديل مواضع الوحدات.
- `MarketHeatmap` يحول التغير إلى لون دون اختلاق قيمة.
- `persistLayout` و`restoreLayout` لحفظ layout محلياً؛ لا يتم حفظ بيانات حساسة أو أسعار خام.

## قرار السلامة

الحزمة لا تجلب البيانات ولا تكتب إلى قاعدة البيانات. التطبيق يمرر `renderWidget` وبيانات السوق بعد التحقق من API envelope، لذلك يمكن اختبار التخطيط دون اتصال خارجي.
