# @borsaty/charts

حزمة عقد للمخططات المالية، وليست بديلاً عن مزود بيانات.

## الحالة الحالية

- الرسم الحالي في التطبيق يستعمل `lightweight-charts` ويُستهلك عبر adapter.
- المؤشرات المحلية المثبتة فعلياً: SMA، EMA، RSI، MACD، Bollinger Bands، ATR.
- registry يحتوي أكثر من 60 تعريفاً؛ التعريفات غير المحلية موسومة `provider` أو `planned` ولا تعرض كميزات منفذة.
- `fcsapi/chart-js` تمت مراجعته من المستودع الرسمي. يتطلب `accessKey` ومفتاح WebSocket منفصل، لذلك لا يُفعّل في الإنتاج حتى يتم توفير مفاتيح واعتماد مزود البيانات ومراجعة الخصوصية.
- Replay Mode يعمل على candles موحدة ولا يدعي backtest تنفيذياً.

## سلامة البيانات

كل candle يمر عبر `normalizeChartCandle`. الأسعار غير الرقمية أو OHLC غير المنطقية تُرفض، وvolume غير المتاح يتحول إلى `null`.
