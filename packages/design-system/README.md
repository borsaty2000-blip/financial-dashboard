# @borsaty/design-system

نظام تصميم مالي مشترك لواجهات بورصتي Web وMobile.

## المبادئ

- الأرقام المالية تستخدم `JetBrains Mono` و`tabular-nums`.
- الألوان الدلالية ثابتة: positive، negative، neutral، warning.
- كل عنصر تفاعلي يدعم لوحة المفاتيح ويدعم RTL.
- الحالات الثلاث للبيانات إلزامية: loading، available، unavailable.
- لا تظهر `Live` أو أي provenance للمستخدم إلا في موضع المنتج المعتمد؛ provenance يبقى في عقد API وسجلات التشغيل.

## المكونات

تتضمن الحزمة أكثر من 30 مكوناً أولياً: التخطيط، البطاقات، الجداول، التبويبات، النوافذ، النماذج، مؤشرات الأسعار، الحالات، البحث، pagination، sparkline، ومكونات الوصول.

## سياسة التغيير

أي breaking change يحتاج ADR، اختبار snapshot/visual، ومراجعة من مالك الواجهة. لا تستورد الحزمة في التطبيق الحالي حتى تمر بوابة الحزمة المستقلة، ثم يتم الدمج عبر adapter صغير بدلاً من استبدال CSS دفعة واحدة.
