# ترقية Chart Stock Detail — TradingView-style

## المكتبة

يستخدم الشارت `lightweight-charts` إصدار 5.2.1 لرسم الشموع والحجم بكفاءة عالية. تم الحفاظ على بطاقة تحليل السهم الحالية، واستبدال جسم الرسم بمكوّن `TradingViewStockChart`.

## الفريمات

الفريمات المتاحة حالياً مع بيانات تاريخية:

- `1D`: بيانات يومية.
- `1W`: بيانات أسبوعية.
- `1M`: بيانات شهرية.
- `1Y`: بيانات يومية لآخر سنة.
- `5Y`: بيانات يومية لآخر خمس سنوات.

الفريمات التي تظهر في الشريط ولكنها غير متاحة حالياً للأسهم المصرية:

- `1m`, `5m`, `15m`, `30m`, `1H`, `4H`.

عند اختيار فريم intraday تظهر رسالة واضحة مع زر للعودة إلى الفريم اليومي. لا يتم اختلاق بيانات أو تحويل بيانات يومية إلى intraday.

## الميزات

- Candlestick chart بألوان TradingView الداكنة.
- Volume bars اختيارية.
- Crosshair وتفاصيل السعر من المكتبة.
- Zoom بالماوس واللمس والسحب.
- `+` للانتقال إلى آخر شمعة و`-` للملاءمة.
- أزرار `ملاءمة` و`آخر شمعة`.
- تبديل Linear / Logarithmic.
- أحدث شمعة تظهر على يمين الرسم مع ترتيب زمني صحيح.
- Responsive: ارتفاع 350px للهاتف، 500px للتابلت، 600px لسطح المكتب.

## التخزين المحلي

يحفظ المكوّن لكل رمز:

- الفريم المختار، والافتراضي `1D`.
- نوع المقياس `linear` أو `log`.
- تفعيل الحجم أو إخفاؤه.

## حدود البيانات

توفر الفريمات يعتمد على مزود البيانات الحالي وواجهة الشموع. لا يغيّر هذا التحديث Backend أو APIs، ولا يدّعي توفر بيانات لحظية غير موجودة. تظل الإفصاحات القانونية في صفحة السهم كما هي.
