# مرحلة الأرقام الإنجليزية ودمج التحليل — 14 سبتمبر 2026

## النطاق

تم توحيد عرض الأرقام المالية في الواجهة إلى أرقام لاتينية باستخدام `en-US` مع إبقاء اللغة والشرح العربيين. يشمل ذلك القيم والأسعار والنسب والتواريخ في الصفحة الرئيسية، صفحة تفاصيل السهم، الحساب، الأخبار، التقويمات، المحاكاة، وسجل الأمان. القيم غير المتاحة تبقى `—` ولا تتحول إلى أرقام افتراضية.

أضيفت لوحة **لوحة التحليل المدمج** في صفحة تفاصيل السهم. تجمع اللوحة، كلما توفرت بيانات تاريخية صحيحة، المؤشرات الفنية (RSI/MACD/SMA20)، Elliott Wave، Gann، Consensus، الإحصاء والمخاطر (Volatility/VaR/Sharpe)، خطوط ARIMA وLSTM التعليمية، ونتائج Backtest المؤهلة. كما تستمر اللوحة القديمة في عرض Ensemble والمشاعر ورصد الشذوذ. كل محرك مستقل؛ فشل أحدها لا يمنع عرض بقية النتائج.

## ملاحظات وحدود

الاختبار المحلي الأول استخدم عملية قديمة على المنفذ نفسه، فأظهر 502 لخدمات الإحصاء والتنبؤ والـBacktest. بعد إخلاء المنفذ وتشغيل نسخة نظيفة، عادت الخدمات الثلاث إلى fallback Node التعليمي بحالة HTTP 200. لا يعني fallback أنه بث سوق أو تنبؤ مضمون؛ يعرض النموذج والحدود التعليمية ضمن العقد.

لم يتم دفع هذه المرحلة إلى GitHub أو نشرها خارجياً. يلزم اختبار نشر مستقل وموافقة صريحة قبل أي تغيير في الإنتاج.
