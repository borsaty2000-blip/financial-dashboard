# مرحلة إثراء الصفحات حسب نشاط القسم — 15 سبتمبر 2026

## الهدف

رفع كثافة وفائدة الصفحات العامة دون وضع محتوى غير مرتبط بالسياق. أضيف شريط نشاط مشترك يظهر بعد محتوى الصفحة، ويختار روابطه تلقائياً وفق المسار الحالي.

## التغطية

| القسم                 | روابط النشاط المرتبطة                                           |
| --------------------- | --------------------------------------------------------------- |
| الأسواق               | EGX، TASI، فاحص الأسهم، الذهب والفضة                            |
| التحليل               | Elliott Wave، Gann، Backtest، مقارنة الأسهم                     |
| الأخبار               | كل الأخبار، التقويم الاقتصادي، الأرباح، التوزيعات               |
| التعلم                | الأكاديمية، الفيديو، الندوات، المجتمع                           |
| مساحة العمل           | قوائم المتابعة، التنبيهات، المحفظة الافتراضية، التقرير الأسبوعي |
| الصفحات العامة الأخرى | مركز بورصتي وروابط الأسواق والتحليل والأخبار والتعلم            |

كل رابط ينقل إلى مسار فعلي عبر router الداخلي، وكل زر قابل للوحة المفاتيح، مع تصميم RTL ومتجاوب ووضع داكن.

## التحقق

نجح `npm run typecheck`، وESLint للمكوّن و`App.tsx`، واختبارات الواجهة: 94 ناجحة و6 متخطاة، وبناء الإنتاج. أظهر فحص المتصفح شريط «غرفة الأخبار» في `/news` مع روابط الأخبار والتقويم والأرباح والتوزيعات، وشريط «مركز بورصتي» في الصفحة الرئيسية.

هذه المرحلة محفوظة محلياً ولم تُنشر خارجياً بعد.
