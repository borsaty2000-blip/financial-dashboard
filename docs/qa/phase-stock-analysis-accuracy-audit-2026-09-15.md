# تدقيق دقة تحليل السهم — 15 سبتمبر 2026

## المشكلات الفعلية التي كُشفت

كان endpoint التحليل الموحد يسمح بتشغيل الغرفة عند توفر 3 أسعار فقط. هذا لا يكفي للتحليل الفني أو الاختبار التاريخي، وكان يمكن أن يؤدي إلى ظهور نتائج fallback بصيغة مكتملة. كذلك كان عداد الواجهة يعرض المحركات المكتملة دون تمييز واضح بين المحرك المحسوب ومحرك fallback التعليمي. وأخيراً كان دليل السوق يعرض اسم الشركة في الصف، لكن الاسم لا ينتقل إلى رأس غرفة التحليل عند فتح السهم.

## الإصلاحات

أصبح التحليل الموحد يرفض التاريخ الأقل من 60 جلسة برسالة عدم توفر صريحة. كما يعيد `engine_statuses` لكل محرك بحالات `computed` أو `educational_fallback` أو `unavailable`، وتعرض الواجهة عدد المحركات التعليمية الاحتياطية للمستخدم. أضيفت رسالة جودة بيانات تؤكد أن النتائج ليست قرار شراء أو بيع وأن الأسعار لا تضمن الفورية.

أصبح الضغط على سهم من دليل EGX أو TASI ينقل اسم الشركة مشفراً في الرابط، وتعرض غرفة التحليل الاسم بجوار الرمز. هذا لا يخترع أسماء: إن لم يوجد اسم عربي قاموسي، يُعرض الاسم الذي عاد به دليل السوق.

## ما يزال يحتاج انتباهاً من المستخدم

قد تكون بعض المحركات التعليمية أو نماذج forecast غير متاحة أو fallback حسب بيئة Python والمصدر. لذلك لا تُعرض نتائجها كضمان. وقد لا تتوفر البيانات الأساسية أو الإفصاحات أو أسعار كل أسهم الدليل؛ عندها يظهر `—` أو حالة عدم التوفر. كما أن التغطية السعرية الحالية ليست لحظية مضمونة بسبب قيود الترخيص، ولا ينبغي استخدام الشاشة وحدها لاتخاذ قرار تداول.

## التحقق

نجح `npm run typecheck`، و`npm run test:server` مع 22 اختباراً، و`npm test -- --run` مع 94 اختباراً ناجحاً و6 اختبارات تكامل خارجية متجاوزة، و`npm run build`. كما تم اختبار عقد الإنتاج السابق لـCOMI بنجاح HTTP 200 مع إعلان جودة البيانات.
