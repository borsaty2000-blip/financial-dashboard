# تدقيق الأسهم والتحليل — 17 سبتمبر 2026

## النتيجة

تم تدقيق كتالوجي السوق المصري والسعودي، ومقارنة ملفات JSON المستوردة مع قاعدة البيانات ومسارات دليل الأسهم. يحتوي الكتالوج المرجعي على **145 شركة EGX** و**419 شركة TASI**. لا توجد رموز مكررة، ولا سجلات بلا رمز أو اسم عربي، ولا تصادمات بين رموز السوقين.

قاعدة البيانات تحتوي على **145 سجل EGX** و**419 سجل TASI**، ولذلك فإن الاستيراد نفسه مكتمل.

## المشكلة المكتشفة

كان endpoint قائمة TASI يعرض أول 100 سجل فقط عندما ينجح SAHMK، لأن المزود يعيد قائمة محدودة بينما الكتالوج المرجعي يحتوي على 419 شركة. لذلك كانت أسهم صحيحة غير ظاهرة رغم وجودها في قاعدة البيانات وملف Excel.

كما كان endpoint قائمة EGX يعود بقائمة فارغة عند تعذر قاعدة البيانات ومزود Twelve Data معاً، بدلاً من استخدام الكتالوج المضمّن.

## الإصلاحات

تم جعل الكتالوج المرجعي المضمّن fallback دائماً عند تعذر قاعدة البيانات أو المزود. وتم دمج نتيجة SAHMK مع كتالوج TASI؛ تُستخدم بيانات المزود عندما توجد، وتبقى بقية الشركات من الكتالوج المرجعي. هذا يمنع تقليص القائمة إلى 100 شركة.

تم أيضاً تحسين حل رموز EGX من ISIN، بحيث يمكن تحويل `ABUK.CA` أو رموز `EGS...` المدعومة إلى الرمز المختصر عند توفره، مع عدم إسقاط الرمز إذا تعذر المصدر الخارجي.

## تحقق HTTP المحلي

بعد الإصلاح، أعاد endpoint TASI:

```text
count: 419
has_1010: true
has_2222: true
source: Twelve Data
freshness: delayed
```

وتأكد endpoint EGX من:

```text
count: 145
has_COMI: true
has_IEEC: true
```

لا تعني `freshness` في دليل الشركات أن أسعار كل الشركات لحظية؛ هي حالة مصدر الدليل فقط. يجب أن يعتمد السعر والتحليل على `data_quality` الخاص بالاقتباس والشموع، لا على حالة دليل الشركات.
