# مراجعة الإطلاق قبل عرض المستثمر — 14 سبتمبر 2026

## الحكم التنفيذي

القرار الحالي **Conditional / مشروط** وليس Go. المنصة تعمل تقنياً، لكن لا ينبغي تقديمها كمنصة بيانات سوق حية مكتملة أو كمنتج استثماري جاهز قبل إغلاق فجوات البيانات والأمن والواجهات الموضحة أدناه.

## نتائج الإنتاج

- `/api/health` وملخصات EGX/TASI والمعادن والأخبار والتحليلات وOpenAPI تعيد HTTP 200.
- ملخصات السوق والمعادن تعيد `available:false` عند غياب مزود صالح؛ TASI يذكر غياب `SAHMK_API_KEY`، والمعادن تذكر عدم تهيئة جسر EGX الرسمي.
- الأخبار تعيد `available:false` وقائمة فارغة عندما لا توجد مصادر موثوقة.
- Elliott وGann يعيدان 200 بحالة `fallback` التعليمية، وليسا دليلاً على تشغيل Python الأصلي أو توصية استثمارية.
- `/api/watchlists` يعيد 401 بلا Token، وهو سلوك حماية متوقع.
- أزمنة الطلبات الخارجية الملحوظة تقريباً 2.8–4.2 ثوانٍ وتحتاج cache/observability قبل تجربة المستثمر.

## نتائج الأمن وجودة الكود

- مسار `POST /api/achievements/award/:code` محمي بتسجيل دخول فقط ويمكنه منح إنجاز ذاتياً؛ يجب حذفه أو تقييده إلى admin/internal وربط المنح بأحداث قابلة للإثبات.
- refresh/reset tokens مخزنة كنص صريح في قاعدة البيانات؛ يلزم hash وتدوير وإبطال مضبوط قبل اعتبار المنتج جاهزاً تجارياً.
- rate limiting داخل Map في الذاكرة ولا يصلح وحده في Serverless؛ يلزم مخزن موزع مثل Redis وضبط proxy وRetry-After.
- `prisma migrate deploy` داخل Vercel build حل schema drift لكنه يحتاج لاحقاً إلى pipeline منفصل مع backup/rollback وadvisory lock.
- `express.json()` يحتاج حدود payload صريحة.
- CSP الحالية واسعة (`https:`, `wss:`, `unsafe-inline`) وتحتاج allowlist ومراجعة تدريجية.
- npm audit أظهر 3 High في سلسلة Prisma/deepmerge-ts وفق التدقيق؛ يلزم triage واختبار توافق قبل الإنتاج.
- lint الكامل يحتوي debt موروثاً كبيراً ويجب عزله وإصلاحه قبل بوابة جودة نهائية.

## نتائج الواجهة

- `/leaderboard` غير معرف؛ التنفيذ الحالي `/community/leaderboard`.
- `/learning` غير معرف؛ التنفيذ الحالي `/education`.
- `/education` قد يعرض تحميلًا/فراغًا غير مفيد عندما تعيد API قائمة فارغة.
- `/strategies` يحتاج ErrorBoundary/timeout أفضل للـlazy chunk حتى لا يظل على spinner عند فشل تحميل chunk.
- الصفحات المحمية تحتاج اختبار authenticated بصري مستمر، خصوصاً portfolio/dashboard.
- الصفحة الرئيسية والتسجيل والدخول ظهرت RTL وبحالات `—` صريحة عند عدم توفر البيانات.

## ما يجوز قوله للمستثمر

يجوز تقديم المشروع كتجربة تقنية عربية تعليمية معمارياً متقدمة، مع الإفصاح أن بعض البيانات والمزودات غير مفعلة وأن التحليلات قد تكون fallback تعليمياً. لا يجوز ادعاء بيانات لحظية مضمونة، Python AI إنتاجي، traction، إيرادات، عوائد أو حقوق إعادة توزيع بيانات دون أدلة وعقود.
