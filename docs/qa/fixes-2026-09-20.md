# تقرير إنقاذ BorsatyAI — 2026-09-20

## ملخص تشخيصي

أظهر فحص الإنتاج أن `GET /api/health` يعيد HTTP 200، بينما وظيفة Python أعادت HTTP 500، وأن آخر نشر مرتبط بالـ commit `3d13b84` كان في حالة `ERROR`. سبب فشل النشر المؤكد من Vercel هو:

> `vercel.json schema validation failed: functions.api/index.ts.includeFiles should be string`

كان `includeFiles` مصفوفة، بينما يتطلب Vercel نمط glob نصياً. لذلك بقي الإنتاج على نشر أقدم، وهو ما يفسر استمرار النصوص القديمة رغم إصلاحها في المستودع.

## الإصلاحات المنفذة

1. تصحيح `vercel.json`:
   - `api/index.ts.includeFiles` أصبح glob نصياً `server/**`.
   - إضافة `api/python/**/*.py` مع `includeFiles: server/python-services/**`.
2. تغيير أولوية الشموع للسوق السعودي إلى SAHMK ثم Twelve Data ثم المصادر الأخرى. يبقى Twelve Data هو المصدر الأول لـ EGX.
3. تبسيط شريط بيانات السهم من أربع بطاقات داخلية إلى ثلاث بطاقات مفيدة:
   - السعر وحالته.
   - آخر إغلاق.
   - المصدر.
4. إزالة عرض الكتالوج وجودة الشموع واعتمادية المحرك من الشريط الرئيسي، مع إبقاء حالة السعر والمصدر بشكل صريح.
5. إزالة العبارات التقنية من اللوحة:
   - لا يظهر `fallback` أو `Python` أو «الوضع الاحتياطي» أو «تجريبي» في صفحة السهم.
   - عند عدم توفر تحليل محدد تظهر العبارة المفهومة: «التحليل غير متاح لهذا الرمز».
6. الإبقاء على الإفصاحات القانونية وعدم إخفاء حقيقة تأخر البيانات أو مصدرها.
